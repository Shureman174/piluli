# Руководство пользователя

## Установка и настройка приложения

### Загрузка APK

Сборка APK может быть выполнена двумя способами: через Android Studio или командную строку.

#### В Android Studio

1. Откройте проект в Android Studio.
2. Выберите `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
3. APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.

#### Из командной строки

```bash
cd c:\Users\Shureman\Documents\New project\contraceptives
gradlew.bat assembleDebug
```

Установите APK на устройство:

1. Перетащите сгенерированный APK файл на ваш Android-устройство.
2. Установите приложение через установщик.

## Настройка напоминаний

Настройте время напоминания:

1. Откройте главный экран приложения.
2. Нажмите кнопку с текущим временем напоминания (по умолчанию 09:00).
3. Выберите нужное время в диалоговом окне.
4. Нажмите OK — приложение начнет отправлять вам уведомления в это время ежедневно.

## Управление препаратами

### Добавление нового препарата

1. Перейдите на экран "Препараты".
2. Нажмите кнопку "+ Добавить препарат".
3. Заполните форму с информацией о препарате и нажмите OK.

### Редактирование существующего препарата

1. Перейдите на экран "Препараты".
2. Найдите препарат, который нужно редактировать.
3. Нажмите на препарат для отображения подробной информации и кнопку "Изменить".

### Архивирование препарата

1. Перейдите на экран "Препараты".
2. Найдите препарат, который нужно архивировать.
3. Нажмите на препарат для отображения подробной информации и кнопку "Архивировать".

### Удаление препарата

1. Перейдите на экран "Препараты".
2. Найдите препарат, который нужно удалить.
3. Нажмите на препарат для отображения подробной информации и кнопку "Удалить".

### Просмотрите список препаратов

Перейдите на экран "Препараты". Вы увидите список всех препаратов с возможностью выбора для редактирования или архивации.

## Заключение

"Медицинская система управления препаратами" — это полезный инструмент для хранения и управления информацией о препаратах. Система позволяет пользователям эффективно добавлять, редактировать, архивировать и удалять препараты, что способствует более организованному управлению медикаментозным запасом.

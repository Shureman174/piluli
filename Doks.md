# Документация

## Обзор

"Медицинская система управления препаратами" — это инструмент для хранения и управления информацией о препаратах. Система позволяет пользователям добавлять, редактировать, архивировать и удалять препараты, а также просматривать текущий список препаратов.

## Основные функции

### Добавление препарата
Пользователь может добавить новый препарат в систему. Для этого используется форма для ввода данных о препарате (название, дозировка, тип, изображение, комментарий, цвет).

**Пример кода:**
```kotlin
data class Medication(
    val id: Long = 0,
    val name: String,
    val dosage: String,
    val type: String,
    val imageUrl: String? = null,
    val comment: String? = null,
    val color: String? = null
)
```

### Редактирование препарата
Пользователь может редактировать существующий препарат. Для этого используется форма для ввода и обновления данных о препарате.

**Пример кода:**
```kotlin
@Dao
interface MedicationDao {
    @Update
    suspend fun update(medication: Medication)
}
```

### Архивирование препарата
Пользователь может пометить препарат как архивированный. Это делается путем изменения состояния записи в базе данных.

**Пример кода:**
```kotlin
data class Medication(
    val id: Long = 0,
    val name: String,
    val dosage: String,
    val type: String,
    val imageUrl: String? = null,
    val comment: String? = null,
    val color: String? = null,
    val isArchived: Boolean = false
)
```

### Удаление препарата
Пользователь может удалить препарат из системы.

**Пример кода:**
```kotlin
@Dao
interface MedicationDao {
    @Delete
    suspend fun delete(medication: Medication)
}
```

### Просмотр списка препаратов
Пользователь может просматривать текущий список всех препаратов. Для этого используется запрос к базе данных.

**Пример кода:**
```kotlin
@Dao
interface MedicationDao {
    @Query("SELECT * FROM medication")
    fun getAll(): Flow<List<Medication>>
}
```

## Устройство и архитектура

### Данные

Используется Room для локальной базы данных SQLite. Модели данных (Entity) хранят информацию о препаратах.

### Репозиторий
Репозиторий предоставляет доступ к данным через DAO (Data Access Object). Включает методы для добавления, обновления, удаления и получения списка препаратов.

### Сервисы
Сервисы отвечают за логику бизнес-процессов. Пример: сервис для управления архивацией препаратов.

## Инструменты
- **Android Jetpack Compose**: Для создания пользовательского интерфейса.
- **Room**: Для работы с базой данных SQLite.
- **Kotlin Coroutines**: Для асинхронных операций.

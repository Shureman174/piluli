# piluli

Приложение для учета лекарственных средств и управления режимом приема препаратов.

## Основные функции
*   **Управление лекарствами**: Функционал добавления, хранения и отображения информации о препаратах.
*   **Offline-first подход**: Все данные сохраняются локально в базе данных Room, что обеспечивает доступ к информации без интернет-соединения.
*   **Интуитивно понятный интерфейс**: Современный UI на базе Jetpack Compose для удобного взаимодействия с пользователем.

## Технологический стек
*   **Язык:** Kotlin (Coroutines, Flow)
*   **UI Framework:** Jetpack Compose
*   **Архитектура:** MVVM + Clean Architecture (слои: Data, Domain, UI)
*   **База данных:** Room
*   **Инъекция зависимостей:** Hilt
*   **Тестирование:** JUnit 5, MockK, Compose Test Rule

## Статус разработки
Проект находится в стадии активной разработки. На текущем этапе реализован основной цикл работы с данными лекарств (CRUD), базовый интерфейс добавления препаратов и автоматизированная система тестирования компонентов.
